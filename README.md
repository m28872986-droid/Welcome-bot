# RipBot

## التشغيل على Render
- Build: `npm install`
- Start: `node index.js`
- Environment Variable: `DISCORD_TOKEN`

## أمر /id
- `/id room` ثم اختر الروم لمعرفة ID الروم.
- `/id role` ثم اختر الرول لمعرفة ID الرول.
- `/id member` ثم اختر العضو لمعرفة ID العضو.

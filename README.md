# RipBot !ty

اكتب `!ty` في الديسكورد ليُرسل لوحة اختيار الألوان.

- القائمة المنسدلة: «اختر لونك...»
- الألوان من 1 إلى 24
- كل رقم مربوط بالـRole ID الخاص به
- اختيار لون جديد يحذف لون الألوان السابق تلقائيًا

Render:
Environment Variable: `DISCORD_TOKEN`
Start Command: `npm start`

يجب أن تكون رتبة البوت أعلى من رتب الألوان وأن يملك Manage Roles.
